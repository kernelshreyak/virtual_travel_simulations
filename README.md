# Virtual Travel Simulations

A collection of editable, Markdown-based virtual travel journals. Each journey records a route, key stops, and current progress.

## Add a Journey

1. Create a clearly named Markdown file, for example `lisbon_to_dakar.md`.
2. Add a title, a direct Google Maps route link, a compact itinerary, and current status.
3. Add the journey to the table above.

Use this small starting template:

```md
# Journey Title

One-line description.

## Route

- **Start:**
- **Destination:**
- **Travel mode:**
- **Google Maps:** [Open the route](https://maps.google.com/)

## Itinerary

| Area | Stops and plans |
| --- | --- |
| Start | |
| Destination | |

## Current Status

- **Current location:**
- **Next major leg:**
- **Goal:**

```

## Conventions

- Keep each journey self-contained in one Markdown file.
- Use a Google Maps link as the route reference.
- Prefer short tables over long notes.
- Update the status when the journey moves to a new area.
